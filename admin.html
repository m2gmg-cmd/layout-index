액세스 토큰 입력

이미지·텍스트를 저장하려면 이 저장소에 쓰기 권한이 있는 GitHub 토큰이 필요합니다. 토큰은 이 브라우저에만 저장되고 GitHub 외부로 전송되지 않습니다.

토큰 만드는 법

연결할 저장소:

  1. github.com → 우측 상단 프로필 → Settings
  2. 맨 아래 Developer settings → Personal access tokens → Fine-grained tokens
  3. Generate new token
  4. Repository access → Only select repositories → 위 저장소 선택
  5. Permissions → Repository permissions → Contents 를 Read and write 로
  6. Generate token → github_pat_... 복사해서 위에 붙여넣기
만료일이 지나면 다시 만들어 입력하면 됩니다. 분실·유출 시 GitHub에서 즉시 revoke 가능.
